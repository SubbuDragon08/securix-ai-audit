Questions

What permissions does it ask for?

Microsoft: AuditLogsQuery.Read.All to read Copilot audit records, and SensitivityLabel.Read to turn label IDs into readable names. Google: admin.reports.audit.readonly. All read-only. You can revoke Microsoft access under Enterprise applications in Entra at any time.

Does it read our actual prompts?

No. It reads metadata only — who, when, which app, and which files the assistant opened. Prompt and response text lives in users' mailboxes and is never requested.

Does anything get sent to SecuriX?

No. There is no backend. The app contacts only Microsoft and Google endpoints to fetch your own data. The report is written to your disk and stays there.

Who needs to run it?

Microsoft: an account with Audit Reader, Audit Manager, or Global Reader, and a licence including Purview Audit. Google: a Super Admin, plus a Gemini for Workspace licence. Google's Gemini audit logging starts from 2025-06-20.

Can I run it on Windows Server?

Yes, with Desktop Experience installed. Server Core has no GUI. For fleet deployment the installer supports /S for silent install and /S /allusers for machine-wide.

How long does it take?

Google returns in seconds. Microsoft's Purview audit search runs server-side and commonly takes 5–20 minutes on a large tenant — the app shows a live timer and can be cancelled at any point.

This shows sanctioned AI only

Your report covers Copilot and Gemini — the AI your tenant knows about. It cannot see ChatGPT, Claude, Cursor, or coding agents on personal accounts, because none of that touches your audit log. That gap is what SecuriX closes.
