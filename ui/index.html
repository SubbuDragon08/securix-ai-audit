Google setup (one time, about 3 minutes)

Google has no equivalent of a shared app you can just approve, so you create a read-only OAuth client inside your own Google Cloud project. Nothing is shared with SecuriX. Sign in to every link below as a Super Admin of your Workspace domain.

  1. Create or pick a project. Any name. An existing project is fine.
  2. Turn on the Admin SDK API. Press Enable. If it already says "Manage", it is on. Check the project name in the top bar first.
  3. Configure the consent screen. Choose Internal — your own staff only, and no Google review. Fill in an app name and your email, then Save.
    Internal greyed out? You are signed in with a personal @gmail.com account. Switch to your Workspace admin account.
  4. Add the read-only scope. On the Scopes step choose Add or remove scopes, paste this into the filter box, tick it, then Update: https://www.googleapis.com/auth/admin.reports.audit.readonly
  5. Create the credential. + Create credentials → OAuth client ID → Application type Desktop app → Create. Not "Web application" — Desktop is what allows the local sign-in callback.
  6. Paste both values below. Google shows them once in a dialog; you can always reopen the client to copy them again.

Stored locally in this app's settings, never transmitted to SecuriX. Google does not treat installed-app secrets as confidential.
